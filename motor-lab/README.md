# مِحرك — مختبر تفاعلي لقطع المحرك

نموذج أولي يختبر تحويل صفحات دليل صيانة المحركات المرفق إلى تجربة تعليمية تفاعلية. المثال الحالي فلتر زيت ثلاثي الأبعاد صُممت هندسته **برمجيًا** باستخدام Three.js، وليس نموذجًا ثلاثي الأبعاد جاهزًا ولا ملف CAD صادرًا عن Volvo.

## ماذا يوجد هنا؟

- مجسّم 3D للفلتر: يمكن تدويره وتكبيره باللمس أو الماوس.
- أوضاع العرض: مكتمل، إخفاء الغلاف لرؤية الداخل التوضيحي، وتفكيك توضيحي متحرك.
- اختيار الغلاف، ووسط الترشيح، والقاعدة، من القائمة أو بالنقر على المجسّم.
- زر تدوير تلقائي وإعادة ضبط زاوية الرؤية.
- واجهة عربية متجاوبة للجوال والكمبيوتر، مع الرسم الأصلي ومعلومات المصدر والتنبيهات.
- نسخ محلية من Three.js وOrbitControls؛ لا يحتاج تشغيل المجسّم إلى Sketchfab أو CDN.

## شغّل الموقع محليًا

يحتاج خادم ملفات ثابتًا، ولا يحتاج إلى بناء أو تثبيت حزم:

```bash
cd motor-lab
python3 -m http.server 8082
```

افتح `http://localhost:8082/` في متصفح حديث يدعم WebGL. في الهاتف استخدم عنوان حاسوبك على الشبكة المناسبة. لا تفتح `index.html` مباشرة من `file://`؛ وحدات JavaScript قد تمنعها سياسات المتصفح. التطبيق لا يتطلب خلفية أو قاعدة بيانات، ولا يجمع بيانات ولا يستدعي خدمات ذكاء اصطناعي. التشغيل يحتاج تنزيل الملفات أول مرة، ولم يُضف Service Worker أو وضع عمل دون اتصال صراحةً.

### نشر ثابت

انشر محتويات هذا المجلد كما هي على أي استضافة ثابتة تدعم JavaScript modules وWebGL، مثل GitHub Pages أو Cloudflare Pages أو Netlify. مسارات الملفات نسبية؛ يمكن أيضًا نشر المجلد كمسار فرعي تحت موقع قائم. ينبغي أن يقدم الخادم `.js` بنوع JavaScript مناسب ويدعم HTTPS للإنتاج.

النموذج التجريبي الذي نُشر أثناء تطوير النسخة الأولى على خدمة Ship.page مستقل عن المستودع ومؤقت، وينتهي في **20 نوفمبر 2026 الساعة 03:14 UTC**؛ لا تعتمد عليه لاستضافة مستمرة. إذا احتجت رابطًا دائمًا فأنشئ استضافة مملوكة لك، وراجع شروط الخدمة والصلاحيات وحقوق المحتوى.

## المصدر وما نعرفه

- الدليل المرفق: `PA1561`، ويتناول Volvo D13 وDetroit Diesel Series 60.
- الرسم المستخدم: Volvo D13F جهة الشاحن التوربيني، **الشكل 2**، صفحة PDF **11**، الصفحة المطبوعة **7**؛ الرقم **20 = Oil Filters**.
- يظهر الرسم فلاتر الزيت، لكنه لا يوفر في هذه الصفحة أبعادها التفصيلية أو مقطعها الداخلي أو عدد فتحات القاعدة أو مقاسات القلاوظ.
- الغلاف الأبيض والتناسب والألوان والطيات والقاعدة والثقوب في المجسّم **تصور تعليمي غير مقاس**. ليس دليل تركيب أو شراء أو صيانة. التطبيق يوضح ذلك في الواجهة.
- لا تفترض أن صورة الرسم أو المقاطع تنطبق على جميع إصدارات D13 أو على Series 60. راجع سنة الصنع، ورقم المحرك، ورقم القطعة، ودليل الشركة المعتمد.

راجع [ملف تحليل الكتاب صفحة صفحة](docs/book-map.md) و[سجل البناء والتشغيل](docs/development.md) و[خطة التطوير](docs/roadmap.md).

## السلامة والحقوق

النموذج تعليمي ولا يحل محل إجراءات الشركة المصنّعة، وليس تصميمًا يمكن إنتاجه أو قياسًا أو نصيحة إصلاح. أي معلومات أعطال أو قيم عزم مستقبلية يجب ربطها بالسياق والتأكد منها بواسطة مختص. أصل الدليل والرسوم تابع لأصحاب حقوقه؛ يجب التحقق من حق استخدامه ونشره وتوزيعه، خصوصًا تجاريًا. هنا أدرجنا صورة واحدة من الدليل المرفق لأغراض عرض الفكرة فقط. لم يُرفع ملف PDF كاملًا. Three.js وOrbitControls يخضعان لرخصة MIT المرفقة في `vendor/THREE-LICENSE.txt`.
